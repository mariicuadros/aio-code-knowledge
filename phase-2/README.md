# AIO CODE — Fase 2: contenido y rendimiento

**Inicio documental:** 2026-10-06. **Estado:** preparada; implementación y datos reales pendientes según el componente.

AIO CODE mantiene su identidad como Digital Entity Operating System (DEOS). Fase 1/Brain corresponde aquí al cierre de infraestructura del 3 de octubre y su consolidación de evidencia del 6 de octubre. Esta numeración operativa no reemplaza las etapas históricas descritas en las bitácoras de agosto y septiembre.

## Qué recibimos

Identidad, entidades, grafo, contratos, fuentes, RAG público controlado y siete tipos de registro del Brain. El baseline original permanece congelado parcial en 14/49. Se mantienen ocho bitácoras, 108 imágenes históricas únicas revisadas y 14 capturas de octubre, con sus límites en el [informe de consolidación](../observatory/reports/PHASE-1-BASELINE-CONSOLIDATION-20261006.md).

No se crea un segundo Brain ni otro Ledger. Los contratos de `brain/contracts/` son la entrada común. Este directorio público contiene planes y criterios; los originales restringidos, métricas privadas y registros operativos pertenecen al vault. Las credenciales pertenecen al entorno autorizado, nunca a Git.

## Primera entrega recomendada

Una pieza real de MC-001, con master y derivados identificados, procedencia, intervención, derechos/disclosure revisados y al menos una observación de rendimiento con fuente y ventana explícitas. Puede partir de una publicación existente, dejando constancia de que el registro es retrospectivo. Hasta disponer de un conector comprobado, una captura manual autorizada permite probar el circuito sin inventar resultados ni esperar al dashboard.
