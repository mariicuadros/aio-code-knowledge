# AIO CODE Provenance

This directory defines how AIO CODE (AIO-001) records the origin and integrity of research evidence.

## Provenance principles

1. Preserve the original artifact in its original storage location whenever possible.
2. Record the evidence ID assigned by AIO CODE.
3. Preserve the original filename in metadata when a working copy is renamed or relocated.
4. Record the date and, when available, the source/location of the artifact.
5. Use cryptographic hashes such as SHA-256 to verify file integrity when practical.
6. Separate provenance from interpretation: a hash can establish integrity of a file, but does not establish the meaning or truth of a claim.
7. Public release requires explicit designation; historical or restricted evidence must not be treated as public merely because metadata exists in this repository.

## Canonical entities

- `MC-001` — Marii Cuadros, creator/researcher/founder and primary case study.
- `AIO-001` — AIO CODE, research and development methodology/lab.
- `NUX-001` — NUX, fictional narrative universe/subordinate entity.

Evidence records must identify the relevant entity explicitly and must not merge these entities.
