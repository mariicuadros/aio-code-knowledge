# Observatory — AIO CODE

Records observations about how external systems represent AIO-001. This layer is separate from the canonical identity definition.

## Mother experiment

The primary current experiment is documented in:

`instagram-mother-experiment-001.md`

It tests whether a new public Instagram representation, signed **AIO CODE-2026**, produces observable changes in retrieval, recognition, resolution, or description of AIO-001.

The experiment uses a pre-publication registration point (T-9), an actual Instagram publication point (T0), and a 30-day observation window (T+1 to T+30).

The Observatory records observable behavior. It does not claim access to or control over private knowledge graphs, model weights, crawler pipelines, or internal entity-resolution mechanisms operated by external providers.
