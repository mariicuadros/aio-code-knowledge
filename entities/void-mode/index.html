VOID MODE

VOID MODE es un sistema creativo independiente para artistas dentro de AIO CODE, el Digital Entity Operating System (DEOS). Organiza identidad creativa, dirección artística, narrativas visuales y audiovisuales, relaciones del contenido, procedencia y documentación pública estructurada.

Sistema creativo y obra artística no son lo mismo

VOID MODE no es una persona ni un sinónimo de AIO CODE. Tampoco es la estética personal, los personajes ni el multiverso de Marii Cuadros. Marii Cuadros (MC-001) desarrolla el sistema y tiene una implementación artística propia; otros artistas pueden desarrollar expresiones independientes, sujetas a permisos y acuerdos pertinentes.

Documentación antes del contenido

La arquitectura permite preparar registros públicos aprobados, relaciones de identidad y fuentes legibles por sistemas de IA antes de publicar las piezas creativas. Publicar esas fuentes no garantiza que motores externos las indexen, recuperen, interpreten o citen.
