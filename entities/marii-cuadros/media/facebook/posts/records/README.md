# Facebook Photo Records — MC-001

Each Facebook photo has an individual record. The numeric date token in the original filename is the **photo ID/date label supplied by the source naming convention**.

## ID rule

- `photo_id`: exact `DD-MM` token from the original filename.
- `date_label`: same `DD-MM` value.
- No year is inferred unless independently documented.
- The original filename is preserved.
- A filename/date token is not, by itself, proof of Facebook publication time.

The record layer connects each asset to MC-001, source, provenance and content registry without changing the original media filename.
