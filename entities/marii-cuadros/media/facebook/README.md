# Marii Cuadros — Facebook Media

This directory stores selected public-facing Facebook media assets used as entity evidence and identity continuity records for Marii Cuadros.

## Purpose
- Preserve provenance records for selected Facebook images.
- Maintain continuity of the public visual representation of the entity.
- Keep source/platform metadata separate from the original social platform.

## Naming convention
Use: `marii-cuadros-facebook-<asset-type>-<number>.<extension>`

Examples: profile-001.jpg, cover-001.jpg, post-001.jpg.

Facebook remains the source platform; this repository is the provenance/archive layer.

For important assets, record metadata in `entities/marii-cuadros/social/facebook.json`.
