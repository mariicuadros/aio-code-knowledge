## 1. Weekly Overview

Week 04 represented a major transition in the AIO CODE experiment.

The week began with the first external signal from Google Search Console indicating that the project had begun appearing in search-related systems. However, direct searches did not yet show stable visibility for the canonical entity.

During the week, the project expanded its content architecture, assigned specialized roles to different AI systems, prepared YouTube, Instagram, Facebook, Medium, Substack and AIO CODE content, and introduced new experimental elements.

The most important development was the discovery that the original AIO CODE methodology was already being investigated in the United States.

Rather than abandoning the project, this discovery led to the creation of **AIO CODE 2.0**, with a stronger emphasis on documenting the methodology, structuring the experiment and studying entity recognition and AI retrieval.

By the end of the week, AI systems were capable of retrieving information associated with Marii Cuadros under certain conditions, but search-engine entity resolution remained inconsistent.

# 12. Critical Interpretation

The project now has evidence of three different states:

```text
STATE 1
Content exists
        ↓
STATE 2
Search engines begin surfacing individual sources
        ↓
STATE 3
AI systems can retrieve information about the entity
        ↓
STATE 4
Canonical entity resolution is still inconsistent
```

The experiment therefore should not classify the current state simply as:

> "Indexed" or "Not indexed."

Instead, visibility should be measured across several independent dimensions.

---

# 13. New Visibility Model

AIO CODE will distinguish:

### A. Source Indexation

Can a published source be found?

### B. Entity Retrieval

Can information about the entity be retrieved?

### C. Entity Resolution

Is the retrieved information associated with the correct entity?

### D. Entity Representation

Does the system describe the entity correctly?

### E. Citation

Does the system cite canonical sources?

### F. Recommendation

Does the system recommend the entity/project without being forced?

This distinction is now part of the AIO CODE research model.

# 20. Week 04 Conclusion

Week 04 did not produce a simple increase in visibility.

Instead, it produced something more valuable for the research:

**a measurable failure condition.**

The project demonstrated that:

* distributed content is being published consistently;
* individual social profiles are beginning to surface in search;
* AI systems can retrieve information about Marii Cuadros;
* Blogger and Medium content can appear as AI sources;
* retrieval may occur in one language while responses are generated in another;
* AI recognition may require contextual prompting;
* Google Search entity resolution remains inconsistent;
* an alternative identity, "Maria Luisa Cuadros," can appear in search;
* the ecosystem therefore requires a stronger canonical entity architecture.

The project consequently moves from:

**Visibility Experiment**

toward:

# Entity Architecture Experiment
