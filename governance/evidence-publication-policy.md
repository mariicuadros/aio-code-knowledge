# Evidence Publication Policy

## Purpose

Define the rules for exposing AIO CODE evidence while preserving research provenance, privacy, and interpretive discipline.

## Publication rule

Evidence is **not public by default**. An artifact becomes public only when it has been explicitly designated for publication.

### Current public evidence

- `AIO-EVD-0002_2026-08-07_initial-development.jpg.png`

This is the only visual evidence currently designated for public release.

## Restricted and historical evidence

All other historical photographs, screenshots, documents, and videos are treated as restricted/not designated for public release unless separately approved.

A directory named `historical/` inside this public repository is an organizational label, not an access-control mechanism. Private originals must therefore remain in private storage outside this repository.

## Evidence interpretation

Every evidence item must distinguish:

- Observed
- Corroborated
- Verified
- Hypothesized
- Unknown

Evidence should not be used to make causal claims that the artifact itself cannot establish.

## Entity integrity

Evidence must preserve the canonical distinction between:

- `MC-001` — Marii Cuadros
- `AIO-001` — AIO CODE
- `NUX-001` — NUX

No evidence record should imply that these are the same entity.
