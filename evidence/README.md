# AIO CODE Evidence Archive

This directory contains the public evidence record for the development and observation history of AIO CODE (AIO-001).

## Evidence policy

- Original photographs and videos are preserved in restricted/private storage unless explicitly designated for public release.
- Public records may contain descriptive metadata, dates, evidence IDs, and provenance references without exposing all original media.
- Evidence must not be interpreted as proof beyond what it directly documents.
- Each record must distinguish observed facts, corroborated evidence, verified claims, hypotheses, and unknowns.

## Publicly designated visual evidence

- `AIO-EVD-0002_2026-08-07_initial-development` — designated public visual evidence from the early development period.

All other historical photographs and videos remain restricted/private unless separately approved for publication.
