## Definition

**AIO CODE — Artificial Intelligence Optimization Code** is a research project and experimental framework investigating how artificial intelligence systems and search engines identify, retrieve, resolve, represent, connect, cite, and potentially recommend digital entities across distributed public information environments.

AIO CODE is not an AI model, chatbot, search engine, social platform, SEO agency, person, or generative AI system.

## Current Research Evidence

AIO CODE has already produced documented observations across search and AI systems. These observations remain part of the research record and must not be downgraded merely because their mechanisms remain under investigation.

At the same time, observed changes must not be presented as proof of causation without appropriate evidence.

Current evidence states are:

- **Observed** — directly recorded under defined conditions.
- **Corroborated** — supported by multiple independent observations, systems, measurements, or sources.
- **Verified** — sufficiently supported for the specific claim being evaluated.
- **Hypothesized** — proposed explanation or expected relationship not sufficiently established.
- **Unknown** — insufficient evidence.
